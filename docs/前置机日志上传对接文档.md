# 前置机日志文件上传对接文档

> 版本：v1.0
>
> 更新时间：2026-10-13
>
> 适用对象：Windows 前置机开发、测试和部署人员
>
> 对接范围：前置机定期上传本地日志文件到本项目服务器，便于后端在客户现场前置机出现问题时远程排查。本文与《前置机对接接口文档》v1.4 使用同一套企业鉴权。

## 1. 用途与背景

部分前置机部署在客户内网，后端无法直接登录客户机器查看日志。前置机通过本接口把本地运行日志定期上传到服务器，后端据此排查异常。上传由前置机主动发起，服务器只负责接收、落盘与过期清理。

## 2. 认证

与运行时前置机其它接口一致，使用企业鉴权密钥：

| 项目 | 约定 |
|---|---|
| 请求头 | `X-Agent-Key: sk-...`（企业鉴权密钥，与心跳/拉取任务相同） |
| 平台前置机 | 使用平台 Key（`sk-platform-...`） |
| 租户 | 由密钥解析得到，前置机无需额外传租户信息 |

## 3. 上传接口

### 3.1 请求

```http
POST /admin-api/declaration/agent/log/upload
Content-Type: multipart/form-data
X-Agent-Key: sk-replace-with-tenant-enterprise-key
```

表单字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `file` | file | 是 | 日志文件 |
| `instanceName` | text | 是 | 实例名，**必须与心跳上报的 `instanceName` 完全一致** |
| `logTime` | text | 否 | 日志产生时间，格式 `yyyy-MM-dd HH:mm:ss`；缺省用服务器接收时间 |

### 3.2 响应

```json
{
  "code": 0,
  "msg": "",
  "data": {
    "id": 88001,
    "filePath": "logs/1/WH-SH-01/20261013/2f8d4c3e9a7b4d5f8e6c7a9b0d1e2f3a.log",
    "uploadTime": "2026-10-13 17:30:00"
  }
}
```

| 字段 | 说明 |
|---|---|
| id | 日志记录 ID |
| filePath | 落盘相对路径，供后端运维定位文件 |
| uploadTime | 服务器接收时间 |

## 4. 限制与校验

| 项 | 规则 | 违反时错误码 |
|---|---|---|
| 文件大小 | ≤ 50 MiB（可配） | `1050000233` 日志文件超过大小限制 |
| 文件类型 | `.log` / `.txt` / `.gz` / `.zip`（可配） | `1050000234` 日志文件类型不允许 |
| 文件内容 | 非空 | `1050000232` 日志文件为空 |
| instanceName | 非空 | `1050000235` 实例名不能为空 |
| 通道开关 | 服务端未开启时整体拒绝 | `1050000231` 日志上传通道未配置或已关闭 |

> 建议上传**压缩后的**日志（`.gz` / `.zip`），既省带宽也节省服务器磁盘。单文件超过 50 MiB 时请先做日志轮转拆分再上传。

## 5. 上传节奏与重试建议

1. **建议每小时滚动一次**：将当前日志压缩后上传，上传成功后可轮转清理本地旧日志。
2. **失败重试**：建议重试 3 次，间隔 1 / 5 / 15 分钟；连续失败应记入心跳的 `lastError`，让后端通过告警感知"日志上传异常"。
3. **离线补传**：前置机断网期间未上传的日志，恢复后应补传，避免排查时缺档（服务器端不强制要求）。
4. **instanceName 一致性**：日志记录的 `instanceName` 必须与心跳一致，否则排查时无法关联到具体实例。

## 6. 服务器端存储与保留策略

| 项 | 说明 |
|---|---|
| 存储位置 | 服务器本地磁盘 `{base-dir}/logs/{tenantId}/{instanceName}/{yyyyMMdd}/` |
| 文件名 | 服务器用 UUID 重命名，原始文件名存元数据表 |
| 保留时长 | 30 天，超期由服务器每天自动清理（可配 `DANA_AGENT_LOG_RETENTION_DAYS`） |
| 元数据 | 落库 `declaration_agent_log_file`，管理端可按实例/时间查询索引 |

## 7. 联调验收清单

| 验收项 | 操作 | 预期 |
|---|---|---|
| 正常上传 | 用 `.log` 或 `.gz` 文件调用接口 | 返回 `code=0` 与 filePath |
| 鉴权失败 | 不传或传错误 `X-Agent-Key` | 返回 401 / `1050000201` |
| 类型校验 | 上传 `.exe` 等非白名单类型 | 返回 `1050000234` |
| 大小校验 | 上传超过 50 MiB 的文件 | 返回 `1050000233` |
| 实例名 | 上传时 `instanceName` 与心跳不一致 | 排查时无法按实例关联（无报错，需自查） |
| 服务器落盘 | 后端到服务器对应目录查看 | 文件存在且可读 |

## 8. 职责边界

| 事项 | 责任方 |
|---|---|
| 日志轮转、压缩、定时上传、失败重试 | 前置机 |
| 接口鉴权、大小/类型校验、落盘 | 后端 |
| 过期清理（30 天）、存储目录规划 | 后端 |
| 排查时从服务器取日志 | 后端运维 |
