# 前置机监控告警 · 前端对接接口文档

> 版本：v1.0
>
> 更新时间：2026-10-13
>
> 适用对象：前端开发人员（管理端）
>
> 对接范围：前置机实例状态查询、异常/告警日志查询。本文是《前置机监控告警对接文档》的前端配套文档。

## 1. 公共约定

| 项目 | 约定 |
|---|---|
| 基础地址 | `/admin-api` |
| 认证 | 管理端登录态（Bearer Token），`Authorization: Bearer <access-token>` |
| 权限 | 接口要求 `declaration:agent-instance:query` 权限点 |
| 租户 | 仅**系统租户**（租户 ID = 1）可调用，非系统租户返回业务错误码 `1050000207` |
| 分页 | `pageNo` 从 1 开始，`pageSize` 1~200，默认 10 |
| 时间格式 | `yyyy-MM-dd HH:mm:ss`（时间范围筛选参数同样按此格式） |
| 响应结构 | 统一 `{ "code": 0, "msg": "", "data": ... }`，`code = 0` 表示成功 |

分页结果统一结构：

```json
{
  "code": 0,
  "msg": "",
  "data": {
    "total": 12,
    "list": []
  }
}
```

## 2. 接口清单

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/declaration/agent-instance/page` | 前置机实例列表（在线状态） |
| GET | `/declaration/agent-instance/alert/page` | 异常/告警日志分页 |

## 3. 前置机实例列表

### 3.1 请求

```http
GET /admin-api/declaration/agent-instance/page?pageNo=1&pageSize=20
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| pageNo | Integer | 是 | 页码，从 1 开始 |
| pageSize | Integer | 是 | 每页条数，1~200 |

### 3.2 响应

```json
{
  "code": 0,
  "msg": "",
  "data": {
    "total": 3,
    "list": [
      {
        "id": 1001,
        "tenantId": 1,
        "instanceName": "WH-SH-01",
        "ip": "172.30.16.1",
        "version": "1.0.0",
        "channelCode": "Shanghai",
        "tradeModesJson": "[{\"tradeMode\":\"shared\",\"outboxOk\":true,\"inboxOk\":false}]",
        "lastError": "统一 InBox 不可读",
        "lastHeartbeatTime": "2026-10-13 16:20:11",
        "heartbeatTimeoutAlertTime": null,
        "createTime": "2026-09-14 10:00:00",
        "updateTime": "2026-10-13 16:20:11"
      }
    ]
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Long | 实例主键 |
| tenantId | Long | 租户编号 |
| instanceName | String | 实例名（稳定唯一） |
| ip | String | 主机 IP |
| version | String | 前置机版本 |
| channelCode | String | 渠道码 |
| tradeModesJson | String | 贸易模式健康状态 JSON（字符串，前端需自行 `JSON.parse`） |
| lastError | String | 最近错误摘要 |
| lastHeartbeatTime | String | 上次心跳时间 |
| heartbeatTimeoutAlertTime | String | 本轮离线首次告警时间；`null` 表示当前无离线告警 |
| createTime / updateTime | String | 创建/更新时间 |

### 3.3 在线状态判定（前端展示用）

服务端不直接返回 `online/offline` 布尔值，前端按以下规则计算，注意两个字段含义不同：

- **实时在线**：以 `lastHeartbeatTime` 距今是否超过阈值（默认 3 分钟）判断，超过即为"失联"。
- **是否已告警**：`heartbeatTimeoutAlertTime == null` 表示当前无离线告警；非 `null` 表示已触发离线告警（建议红色，可提示首次告警时间）。

二者不可混用：刚失联但未到阈值时 `heartbeatTimeoutAlertTime` 仍为 `null`（尚未告警）。列表页建议以"最后心跳 N 分钟前"为主信息，用告警标记区分"已告警离线"。

阈值默认 3 分钟，由后端 `DANA_AGENT_HEARTBEAT_TIMEOUT_MINUTES` 控制，前端不建议硬编码。

## 4. 异常/告警日志分页

### 4.1 请求

```http
GET /admin-api/declaration/agent-instance/alert/page?pageNo=1&pageSize=20&errorType=HEARTBEAT_TIMEOUT&sendStatus=1&instanceName=WH-SH&beginTime=2026-10-13 00:00:00&endTime=2026-10-13 23:59:59
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| pageNo | Integer | 是 | 页码，从 1 开始 |
| pageSize | Integer | 是 | 每页条数，1~200 |
| instanceName | String | 否 | 实例名，模糊匹配 |
| errorType | String | 否 | 异常类型（见 4.3） |
| sendStatus | Integer | 否 | 发送状态：0 待发送 / 1 成功 / 2 失败 |
| beginTime | String | 否 | 创建时间范围起始，`yyyy-MM-dd HH:mm:ss` |
| endTime | String | 否 | 创建时间范围结束，`yyyy-MM-dd HH:mm:ss` |

### 4.2 响应

```json
{
  "code": 0,
  "msg": "",
  "data": {
    "total": 1,
    "list": [
      {
        "id": 5001,
        "tenantId": 1,
        "instanceName": "WH-SH-01",
        "errorType": "HEARTBEAT_TIMEOUT",
        "bizKey": "instance:1001:2026-10-13T15:00:00",
        "title": "前置机心跳超时告警",
        "content": "- 实例：WH-SH-01\n- 租户：1\n- 上次心跳：2026-10-13 15:00:00\n- 超过 3 分钟无心跳，判定离线\n- lastError：统一 InBox 不可读",
        "sendStatus": 1,
        "sendNum": 1,
        "sendTime": "2026-10-13 15:03:01",
        "errorResult": null,
        "createTime": "2026-10-13 15:03:00",
        "updateTime": "2026-10-13 15:03:01"
      }
    ]
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Long | 主键 |
| tenantId | Long | 租户编号 |
| instanceName | String | 实例名 |
| errorType | String | 异常类型（见 4.3） |
| bizKey | String | 去重业务键（同类型同一事件只告警一次） |
| title | String | 消息标题 |
| content | String | 消息内容（markdown 文本，含 `\n` 换行） |
| sendStatus | Integer | 0 待发送 / 1 成功 / 2 失败 |
| sendNum | Integer | 已尝试发送次数 |
| sendTime | String | 最近一次发送时间 |
| errorResult | String | 最近一次发送失败原因（成功时为 null） |
| createTime / updateTime | String | 创建/更新时间 |

### 4.3 异常类型枚举

| errorType | 含义 | 前端展示建议 |
|---|---|---|
| `HEARTBEAT_TIMEOUT` | 心跳超时（离线） | 红色，高危 |
| `HEARTBEAT_RECOVERY` | 心跳恢复 | 绿色，正常 |
| `DELIVERY_UNKNOWN` | 投递未知（任务无回执） | 橙色，需人工核实 |
| `RECEIPT_FAILED` | 回执失败（ResponseCode != 0） | 橙色 |
| `CLIENT_REPORTED` | 客户端上报异常（预留） | 灰色 |

## 5. 错误码

| code | 说明 |
|---|---|
| 0 | 成功 |
| 1050000207 | 仅系统租户可管理前置机配置（`DECLARATION_AGENT_ADMIN_ONLY`） |
| 401 | 未登录或 Token 失效 |
| 403 | 无权限（缺少 `declaration:agent-instance:query`） |

## 6. 前端接入建议

1. **权限**：菜单/按钮需绑定 `declaration:agent-instance:query` 权限标识，未授权接口返回 403。
2. **在线状态**：以 `heartbeatTimeoutAlertTime` 是否为 null 作为红绿灯判据，`lastHeartbeatTime` 仅用于展示"最后心跳时长"。
3. **异常日志页**：默认按 `createTime` 倒序（服务端已按 id 倒序）；建议默认筛选 `sendStatus=2` 或按 `errorType` 做 tab，便于运维快速定位发送失败的告警。
4. **content 展示**：`content` 为 markdown 文本，直接 `<pre>` 或换行渲染即可，不建议二次解析。
5. **轮询**：实例列表建议 30~60 秒轮询一次，与心跳频率一致即可，无需更频繁。
